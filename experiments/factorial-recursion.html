5 Factorial (Recursion Analysis)

Aim

To compute factorial recursively and count the total recursive calls and the maximum recursion depth for different n.

Algorithm

  1. Call factorial(n, depth) and increment total_calls.
  2. Update max_depth if the current depth is larger.
  3. If n == 0, return 1 (base case).
  4. Otherwise return n * factorial(n-1, depth+1).
  5. Print n, total calls and max depth for each input.

Code

Original code (q5.c)
#include<stdio.h>

int total_calls=0;
int max_depth=0;

int factriol(int n, int depth){
    total_calls++;
    if(depth>=max_depth){
        max_depth=depth;
    }
    if(n==0){
        return 1;
    }
    return n*factriol(n-1,depth+1);
}

int main(){
    int arr[]={5,10,23,123,3451,1232};
    int size=sizeof(arr)/sizeof(arr[0]);
    printf("n\ttotalcalls\tMax depth\n");
    for(int i=0;i<size;i++){
        int n=arr[i];
        total_calls=0;
        max_depth=0;

        factriol(n,1);

        printf("%d\t%d\t\t%d\n",n,total_calls,max_depth);
    }
}

Time Complexity

CaseTime Complexity
BestO(n) – one call per level
AverageO(n)
WorstO(n)

Space Complexity

O(n) – recursion stack of depth n+1

Recurrence Relation

T(n) = T(n-1) + 1, T(0) = 1 ⇒ T(n) = n + 1 = O(n)

Generalised Code (Short Version)

Generalised short version
#include<stdio.h>
long long fact(int n){ return n ? n*fact(n-1) : 1; }
int main(){
    printf("5! = %lld\n",fact(5));
}

Output
