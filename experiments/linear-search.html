1 Linear Search

Aim

To search for a key in an array by checking each element one by one, and count the comparisons made.

Algorithm

  1. Start from index 0 of the array.
  2. Compare the current element with the key and increment the count.
  3. If they are equal, print the index and stop.
  4. Otherwise move to the next element.
  5. If the end is reached, the key is not present.

Code

Original code (q1.c)
#include<stdio.h>
int main(){
    int array[]={1,2,3,4,5};
    int n=sizeof(array)/sizeof(array[0]);
    int key=5;
    int count=0;
    for(int i=0;i<n;i++){
        count++;
        if(array[i]==key){
            printf("element found at index %d",i);
            printf(" and the element is %d\n",key);
            printf("%d",count);
            return 0;

          count++;
        }
    }

}

Sample Input / Output

Sample Input

array = {1,2,3,4,5}, key = 5

Sample Output

element found at index 4 and the element is 5
5

Time Complexity

CaseTime Complexity
BestO(1) – key is at the first position
AverageO(n) – about n/2 comparisons
WorstO(n) – key is last or absent

Space Complexity

O(1) – only a few variables

Recurrence Relation

No recurrence (iterative). T(n) = n comparisons in the worst case.

Generalised Code (Short Version)

Generalised short version
#include<stdio.h>
int lsearch(int a[],int n,int k){
    for(int i=0;i<n;i++) if(a[i]==k) return i;
    return -1;
}
int main(){
    int a[]={1,2,3,4,5};
    printf("index = %d\n",lsearch(a,5,5));
}

Output

index = 4
