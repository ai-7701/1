4 Insertion Sort

Aim

To sort an array by inserting each element into its correct place within the already sorted left part.

Algorithm

  1. Treat a[0] as the sorted part; start i from 1.
  2. Store key = a[i] and set j = i-1.
  3. While j >= 0 and a[j] > key, shift a[j] one place right.
  4. Place the key at a[j+1].
  5. Repeat for all i up to n-1.

Code

Original code (q4.c)
#include<stdio.h>
int main(){
  
    int array[]={4,3,1,6,7};
    int n=sizeof(array)/sizeof(array[0]);

    for(int i=1;i<n;i++){
        int key=array[i];
        int j=i-1;

        while(j>=0 && array[j]>key){
            array[j+1]=array[j];
            j--;
            
        }
        array[j+1]=key;
    }
for(int i=0;i<n;i++){
    printf("%d ",array[i]);
}

}

Sample Input / Output

Sample Input

array = {4,3,1,6,7}

Sample Output

1 3 4 6 7

Time Complexity

CaseTime Complexity
BestO(n) – already sorted
AverageO(n²)
WorstO(n²) – reverse sorted

Space Complexity

O(1) – in-place

Recurrence Relation

No recurrence (iterative). Worst case T(n) = 1 + 2 + … + (n-1) = O(n²)

Generalised Code (Short Version)

Generalised short version
#include<stdio.h>
void insertion(int a[],int n){
    for(int i=1;i<n;i++){
        int k=a[i],j=i-1;
        while(j>=0 && a[j]>k){ a[j+1]=a[j]; j--; }
        a[j+1]=k;
    }
}
int main(){
    int a[]={4,3,1,6,7},n=5;
    insertion(a,n);
    for(int i=0;i<n;i++) printf("%d ",a[i]);
}
