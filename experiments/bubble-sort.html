3 Bubble Sort

Aim

To sort an array in ascending order by repeatedly swapping adjacent elements that are out of order.

Algorithm

  1. Repeat the outer pass i from 0 to n-2.
  2. In each pass compare adjacent elements a[j] and a[j+1].
  3. If a[j] > a[j+1], swap them.
  4. After each pass the largest remaining element settles at the end.
  5. After n-1 passes the array is sorted.

Code

Original code (q3.c)
#include<stdio.h>
int main(){
    int array[]={4,3,1,6,7};
    int n=sizeof(array)/sizeof(array[0]);
    for(int i=0;i<n-1;i++){
       for(int j=0;j<n-i-1;j++){
              if(array[j]>array[j+1]){
                int temp=array[j];
                array[j]=array[j+1];
                array[j+1]=temp;
              }
       }
    }
    printf("Bubble sort output:");   
    for(int i=0;i<n;i++){
        printf("%d ",array[i]);
    }
}

Sample Input / Output

Sample Input

array = {4,3,1,6,7}

Sample Output

Bubble sort output:1 3 4 6 7

Time Complexity

CaseTime Complexity
BestO(n²) as written (O(n) only with an early-exit flag)
AverageO(n²)
WorstO(n²) – reverse sorted

Space Complexity

O(1) – in-place

Recurrence Relation

No recurrence (iterative). T(n) = (n-1) + (n-2) + … + 1 = n(n-1)/2 = O(n²)

Generalised Code (Short Version)

Generalised short version
#include<stdio.h>
void bubble(int a[],int n){
    for(int i=0;i<n-1;i++)
        for(int j=0;j<n-i-1;j++)
            if(a[j]>a[j+1]){int t=a[j];a[j]=a[j+1];a[j+1]=t;}
}
int main(){
    int a[]={4,3,1,6,7},n=5;
    bubble(a,n);
    for(int i=0;i<n;i++) printf("%d ",a[i]);
}
