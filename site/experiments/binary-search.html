2 Binary Search

Aim

To search for a key in a sorted array by repeatedly halving the search range, and count the comparisons.

Algorithm

  1. Set min = 0 and max = n-1 on the sorted array.
  2. Find mid = (min+max)/2 and count the comparison.
  3. If array[mid] equals the key, print the index and stop.
  4. If array[mid] is greater than the key, search left: max = mid-1.
  5. Otherwise search right: min = mid+1; repeat while min <= max.

Code

Original code (q2.c)
#include <stdio.h>

int main(){
    int array[]={1,4,6,7,8};
    int n=sizeof(array)/sizeof(array[0]);
    int min=0;
    int max=n-1;
    int key=6;
    int count=0;

    while(min<=max){
        int mid=(min+max)/2;
        count++;
      

        if(array[mid]==key){
            printf("element found at index mid=%d\n and the element is %d ",mid,array[mid]);
              printf(" no of comparision= %d ",count);
            return 0;
        }else if(array[mid]>key){
             max=mid-1;
        }else{
            min=mid+1;
        }

    }
    
}

Sample Input / Output

Sample Input

array = {1,4,6,7,8}, key = 6

Sample Output

element found at index mid=2
 and the element is 6  no of comparision= 1

Time Complexity

CaseTime Complexity
BestO(1) – key is at the middle
AverageO(log n)
WorstO(log n) – key at the end or absent

Space Complexity

O(1) iterative

Recurrence Relation

T(n) = T(n/2) + 1, T(1) = 1 ⇒ T(n) = O(log n)

Generalised Code (Short Version)

Generalised short version
#include<stdio.h>
int bsearch2(int a[],int n,int k){
    int l=0,h=n-1;
    while(l<=h){
        int m=(l+h)/2;
        if(a[m]==k) return m;
        a[m]>k ? (h=m-1) : (l=m+1);
    }
    return -1;
}
int main(){
    int a[]={1,4,6,7,8};
    printf("index = %d\n",bsearch2(a,5,6));
}
