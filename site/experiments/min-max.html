8 Finding Min and Max (Divide & Conquer)

Aim

To find the maximum and minimum elements of an array using divide and conquer.

Algorithm

  1. Initialise min and max with the first element.
  2. If low == high, compare that single element with min and max.
  3. Otherwise find mid = (low+high)/2.
  4. Recursively process the left half and the right half.
  5. After all calls, min and max hold the answers.

Code

Original code (q8.c)
#include <stdio.h>
int min,max;
void minmax(int arr[],int low,int high){
    int mid;
    if(low==high){
        if(arr[low]<min){
            min=arr[low];
        }
        if(arr[low]>max){
            max=arr[low];
        }
        return;
    }
    mid=(low+high)/2;
    minmax(arr,low,mid);
    minmax(arr,mid+1,high);

}
int main(){
    int arr[]={7,2,9,4,1,6};
    int n=sizeof(arr)/sizeof(arr[0]);
    min=arr[0];
    max=arr[0];
    minmax(arr,0,n-1);
    printf("Maximum element = %d\n",max);
    printf("minimum element = %d",min);

    
    return 0;
}

Sample Input / Output

Sample Input

array = {7,2,9,4,1,6}

Sample Output

Maximum element = 9
minimum element = 1

Time Complexity

CaseTime Complexity
BestO(n)

WorstO(n) – 2(n-1) comparisons as written

Space Complexity

O(log n) – recursion stack

Recurrence Relation

T(n) = 2T(n/2) + O(1), T(1) = 2 ⇒ T(n) = O(n)

Generalised Code (Short Version)

Generalised short version
#include<stdio.h>
void mm(int a[],int l,int h,int *mn,int *mx){
    if(l==h){ *mn=*mx=a[l]; return; }
    int m=(l+h)/2,mn1,mx1,mn2,mx2;
    mm(a,l,m,&mn1,&mx1); mm(a,m+1,h,&mn2,&mx2);
    *mn = mn1<mn2 ? mn1 : mn2;
    *mx = mx1>mx2 ? mx1 : mx2;
}
int main(){
    int a[]={7,2,9,4,1,6},mn,mx;
    mm(a,0,5,&mn,&mx);
    printf("Maximum element = %d\nminimum element = %d",mx,mn);
}

Output

minimum element = 1
