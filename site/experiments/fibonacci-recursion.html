6 Fibonacci (Recursion Tree)

Aim

To compute Fibonacci numbers recursively and count the total calls and leaf nodes of the recursion tree.

Algorithm

  1. Call fib(n) and increment total_calls.
  2. If n <= 1, increment leaf_nodes and return n.
  3. Otherwise return fib(n-1) + fib(n-2).
  4. Measure the elapsed time with clock(); stop if it exceeds 5 seconds.
  5. Print n, total calls and leaf nodes for each input.

Code

Original code (q6.c)
#include<stdio.h>
#include<time.h>

int total_calls=0;
int leaf_nodes=0;

int fabonaci(int n){
    total_calls++;
    if(n<=1){
        leaf_nodes++;
        return n;
    }
    return fabonaci(n-1)+fabonaci(n-2);
}

int main(){

    int arr[]={3,5,6,8,5,2};
    int size=sizeof(arr)/sizeof(arr[0]);

    printf("n\ttotal calls\tleaf nodes\n");

    for(int i=0;i<size;i++){
        int n=arr[i];

        total_calls=0;
        leaf_nodes=0;
        
        clock_t start=clock();
        int result=fabonaci(n);
        clock_t end=clock();

        double elapsed=(double)(end-start)/CLOCKS_PER_SEC;

        if(elapsed>5.0){
            printf("n=%d stoped over (5 seconds)",n);
            break;
        }
        printf("%d\t%d\t\t%d\n",n,total_calls,leaf_nodes);
    }
}

Time Complexity

CaseTime Complexity
BestO(2^n) – no memoisation, tight bound Θ(φⁿ)
AverageO(2^n)
WorstO(2^n)

Space Complexity

O(n) – maximum recursion depth

Recurrence Relation

T(n) = T(n-1) + T(n-2) + 1, T(0) = T(1) = 1 ⇒ T(n) = O(2^n)
